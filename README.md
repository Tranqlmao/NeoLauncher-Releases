NeoLauncher is NeoLegacy's official game launcher. As of now, this launcher is closed source, but this is subject to change!
This launcher will remain closed source until it is determined the goals NeoLegacy will provide for multiplayer and minigame safety.

The goal of this launcher is to have an official means to launch, install, and customize your game! The launcher will support other outside game versions, so it can be used anywhere!

We do not have a plan to discontinue support of any other launcher support, and allow the user to continue using the launcher of their choice.

## Download


Go to the [Releases](../../releases/latest) page and download the file for your system:

| System | Download |
|---|---|
| **Windows 10/11** (64-bit) | `NeoLauncher_x.x.x_x64-setup.exe` |
| **Linux** (64-bit) | `.AppImage` (any distro), `.deb` (Debian/Ubuntu) or `.rpm` (Fedora) |
| **macOS** | `.dmg` (Apple Silicon: `aarch64`, Intel: `x64`) |

> **Linux and macOS:** neoLegacy runs natively to windows, so it runs through **Wine** or **Proton**. Install one of them, then set the command under **Settings → Launcher → Wine command** (for example `wine`). Linux and macOS support is in beta.


## Launcher Features

### Play
- **NeoLegacy** – install and play the latest official neoLegacy build straight from the launcher.
- **Use any build** – import a game folder you already have, or add versions from a custom manifest. Other Legacy Console Edition versions work too.
- **Version picker** – switch builds from the main screen with the "Version selected" menu.

### Always Up to Date
- **Game updates** – when a new neoLegacy release is out, a glowing orb appears next to the version and a notification lets you know. Update whenever you like; you can keep playing the build you have.
- **Launcher updates** – new versions of the launcher install themselves in one click, and every update is signed so you know it's genuine.
- **Your worlds are safe** – updating or uninstalling a version never touches your worlds and settings.

### Profile & Skins
- **Your profile** – set your username right from the main screen.
- **Custom skins** – upload any 64x64 or classic 64x32 skin. Classic and slim arms are detected automatically.
- **Capes** – upload your own cape and see it in game.
- **3D preview** – an inventory-style preview that follows your mouse, with Minecraft lighting. Flip it around to see your cape.

### Workshop
- **Community content** – browse skin packs, texture packs and more from the NeoLegacy Marketplace. All community made.
- **New packs show up automatically** as they're added.

### Themes & Easter Eggs
- **Panoramas** – pick the title screen panorama from a range of themes, with day and night versions.
- **Customize** – change the panorama, night mode and profile colour in the Themes tab, and turn sound effects on or off in Settings.
- **Easter eggs** – see what happens when you click the logo... 🎆

## Questions

**Do I have to stop using my other launcher?**
As of now, this launcher supports the same playability of any other launcher! 
Eventually, it could be required to play minigames, but the team is working hard to avoid this :)

**Where are my worlds kept?**
In each install's folder. Open it from **Settings → Versions → Open Folder**.

**Is the source code available?**
Not yet; see above.
