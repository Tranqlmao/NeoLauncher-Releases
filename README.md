NeoLauncher is NeoLegacy's offical game launcher. As of now, this launcher is closed sourced, but this is subject to change!
As of now, this launcher will remain closed source until it is determined the goals NeoLegacy will provide for multiplayer and minigame safety.


The goal of this launcher is to have an official means to launch, install, and customize your game! The launcher will support other outside game versions, so it can be used anywhere!
We do not have a plan to discontinue support of any other launcher support, and allow the user to continue using the launcher of their choice.


This launcher includes: 
• Custom Themes 
• Direct Version Installation
• Themes and Easter Eggs
• Custom HTML UI
• User-Content Via Workshop
• NeoLegacy News & Featured Creations
