NeoLauncher is NeoLegacy's official game launcher. As of now, this launcher is closed source, but this is subject to change!
This launcher will remain closed source until it is determined the goals NeoLegacy will provide for multiplayer and minigame safety.

The goal of this launcher is to have an official means to launch, install, and customize your game! The launcher will support other outside game versions, so it can be used anywhere!

We do not have a plan to discontinue support of any other launcher support, and allow the user to continue using the launcher of their choice.

## Download

WINDOWS **Requirements:** Windows 10 or 11 (64-bit).
1. Go to the [Releases](../../releases/latest) page.
2. Download **`NeoLauncher_x.x.x_x64-setup.exe`** and run it.
3. That's it! The launcher keeps itself up to date from then on.

Go to the [Releases](../../releases/latest) page and download the file for your system:

| System | Download |
|---|---|
| **Windows 10/11** (64-bit) | `NeoLauncher_x.x.x_x64-setup.exe` |
| **Linux** (64-bit) | `.AppImage` (any distro), `.deb` (Debian/Ubuntu) or `.rpm` (Fedora) |
| **macOS** | `.dmg` (Apple Silicon: `aarch64`, Intel: `x64`) |
